# 00. プロジェクト概要（Overview）

## 本リポジトリの目的

本リポジトリは、当社の事業成長を加速するための**エージェントチーム運用基盤**を定義・管理するものである。

エージェントチームとは、AIエージェント（Claude等）と人間チームが協働し、以下を継続的に実行する仕組みを指す：

- 業務プロセスの改善提案
- 自動化・標準化の実装
- KPIモニタリングと意思決定支援
- ナレッジ・テンプレートの整備

---

## 事業概要

### 対象業界
- 歯科
- 医療
- 介護
- 中小企業

### 提供サービス

| カテゴリ | サービス内容 |
|---------|-------------|
| 高単価コンサル | 顧問契約、組織・人事・採用・業務改善コンサルティング |
| 成果報酬型 | 人材紹介、M&A/事業承継支援 |
| 制作 | HP/LP/SNS/動画等の制作 |
| DX/業務改善 | Google Workspace、Notion、スプレッドシート、GAS、BigQuery等の導入・活用支援 |
| 教材/テンプレ販売 | 採用テンプレート、評価制度、スプレッドシートテンプレート等 |

### 事業戦略

```
フロント（顧客接点・ブランド・信頼）→ 代表が担当
バックエンド（納品・運用・管理）→ 自動化・外注・テンプレ化で粗利最大化
```

## ツール構成

Google Workspaceを中心としたツール構成で運用する。

| 機能 | ツール | 詳細 |
|------|--------|------|
| 案件・顧客管理 | **Sheets** | データベース的に使用。データ検証でプルダウン選択、GASで入力支援 |
| 売上・KPI集計 | **Sheets** | 既存の月別シートを活用、QUERY関数やピボットで集計自動化 |
| 候補者情報 | **Drive** | 現状維持（フォルダ構成の標準化のみ） |
| 成果物管理 | **Drive** | クライアント別フォルダ構成 |
| テンプレート | **Docs/Drive** | 提案書・契約書・指示書等のテンプレート管理 |
| ダッシュボード | **Looker Studio** | Sheetsと連携してKPI可視化 |
| 自動化 | **GAS** | 通知、レポート生成、入力フォーム |
| コミュニケーション | **Gmail/Chat** | 既存のまま |

※ Notionは解約済み（浸透しなかったため）

## エージェントチームが扱う対象領域

単発の制作物ではなく、**事業成長を加速する"仕組み"**を対象とする。

### 優先度順の対象領域

| 優先度 | 領域 | 概要 |
|--------|------|------|
| A | リード→契約→継続 | LTV最大化の仕組み化（獲得→商談→契約→リテンション） |
| B | 納品/運用基盤 | コンサル・制作・DX納品の標準化、少人数運用体制 |
| C | データ基盤 | Sheets/Looker Studio/BigQuery等による可視化と意思決定高速化 |
| D | デジタル資産 | テンプレ/教材の設計・販売導線構築 |
| E | 外注/パートナー運用 | 品質管理、独立リスク対策、契約・成果物管理 |

---

## 期待するアウトカム

1. **代表の時間創出** - 売上/粗利/継続率を上げながら、代表の稼働時間を削減
2. **品質の安定化** - サービス提供品質を一定以上に維持
3. **属人化の解消** - 複製可能・引継ぎ可能な運用体制
4. **KPI可視化** - 事業KPIを週次で追跡可能な状態
