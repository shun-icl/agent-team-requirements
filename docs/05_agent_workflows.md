# 05. エージェントワークフロー設計

> **目的**: エージェントチームの具体的な動作フロー、トリガー、人間との協働ポイントを定義
> **更新頻度**: 運用開始後に随時改善

## 2. 主要ワークフロー

### 2.1 案件登録フロー

**トリガー**: 代表が「新規案件を登録して」と依頼

```
[代表] 「〇〇社から採用コンサルの依頼、月額20万で3ヶ月契約」
    ↓
[エージェント] 情報を構造化
    ├─ 顧客名: 〇〇社
    ├─ サービス: 採用コンサル
    ├─ 金額: 月額20万円
    ├─ 期間: 3ヶ月
    └─ ステータス: 契約済み
    ↓
[エージェント] 確認を求める
    「以下の内容で案件シートに登録します。よろしいですか？
     ・顧客: 〇〇社
     ・サービス: 採用コンサル（高単価コンサル）
     ・月額: 20万円 × 3ヶ月 = 総額60万円
     ・開始日: 本日
     ・請求サイクル: 月末締め翌月払い（デフォルト）」
    ↓
[代表] 「OK」または修正指示
    ↓
[エージェント]
    ├─ 案件管理シートに行追加
    ├─ 顧客マスタに既存チェック（なければ追加確認）
    ├─ Driveにフォルダ作成（クライアント名/案件名/）
    └─ 「登録完了しました。案件ID: A-2026-023」
```

### 2.2 週次KPIレポート生成フロー

**トリガー**: 毎週月曜 or 代表の依頼

```
[代表] 「週次レポートを作って」
    ↓
[エージェント] データ収集
    ├─ 案件管理シートから進行中案件を取得
    ├─ 請求管理シートから未入金を取得
    ├─ リード管理シートから新規リードを取得
    └─ 売上集計シートから今月累計を取得
    ↓
[エージェント] レポート生成
    ┌────────────────────────────────────────┐
    │ 📊 週次KPIレポート（2/10〜2/16）        │
    ├────────────────────────────────────────┤
    │ ■ 売上                                 │
    │   今月累計: 180万円（目標比 72%）       │
    │   先週比: +45万円                      │
    │                                        │
    │ ■ パイプライン                         │
    │   商談中: 3件（想定120万円）            │
    │   提案中: 2件（想定80万円）             │
    │                                        │
    │ ■ 要注意                               │
    │   ⚠️ 未入金: 2件（合計35万円）          │
    │   ⚠️ 今週納品: 〇〇社 HP制作            │
    │                                        │
    │ ■ 今週のアクション提案                 │
    │   1. △△社への請求フォロー             │
    │   2. ××社の提案書作成                 │
    └────────────────────────────────────────┘
```

### 2.3 未入金アラートフロー

**トリガー**: 請求管理シートで支払期限超過を検知

```
[エージェント] 請求管理シートをチェック（日次 or 依頼時）
    ↓
[検知] 支払期限を過ぎた請求を発見
    ├─ 〇〇社: 15万円（期限: 2/10、3日超過）
    └─ △△社: 20万円（期限: 2/5、8日超過）
    ↓
[エージェント] 代表に報告
    「⚠️ 未入金アラート

     1. 〇〇社 - 15万円
        請求日: 1/31、期限: 2/10（3日超過）
        案件: 採用コンサル 1月分
        → フォローメールのドラフトを作成しますか？

     2. △△社 - 20万円
        請求日: 1/20、期限: 2/5（8日超過）
        案件: HP制作 着手金
        → 電話フォローを推奨」
    ↓
[代表] 「〇〇社のメールドラフト作って」
    ↓
[エージェント] メールドラフト生成（送信は人間が確認）
```

### 2.4 提案書作成支援フロー

**トリガー**: 代表が「提案書を作って」と依頼

```
[代表] 「〇〇歯科に採用支援の提案書作って。
       院長が採用に困っている、歯科衛生士2名採用したい」
    ↓
[エージェント] 情報整理 & 質問
    「提案書を作成します。いくつか確認させてください。

     1. 想定サービス
        □ 採用コンサル（月額型）
        □ 人材紹介（成功報酬型）
        □ その他

     2. 想定期間・金額
        □ 月額15万円 × 6ヶ月（例）
        □ 別途提示

     3. 含める要素
        ☑ 課題分析
        ☑ 提供サービス内容
        ☑ 料金プラン
        ☑ 実績（類似案件）
        □ スケジュール」
    ↓
[代表] 「採用コンサル月額15万、課題分析と実績入れて」
    ↓
[エージェント]
    ├─ テンプレートフォルダから「提案書_採用コンサル.docx」を取得
    ├─ 顧客情報を差し込み
    ├─ 過去の歯科案件実績を検索・挿入
    └─ ドラフトを生成
    ↓
[エージェント] 「提案書ドラフトを作成しました。
               Driveリンク: [URL]

               ※ 以下は手動で確認・調整をお願いします：
               - 料金の最終確定
               - 実績部分の具体的な数値
               - 先方担当者名」
```

### 2.5 月次クロージングフロー

**トリガー**: 月初 or 代表の依頼

```
[代表] 「先月の締めをして」
    ↓
[エージェント] 集計処理
    ├─ 案件管理シートから先月完了案件を抽出
    ├─ 請求管理シートから先月請求を集計
    ├─ 売上集計シートに新行を追加
    └─ 入金消込の未完了をリストアップ
    ↓
[エージェント] 確認依頼
    「📊 2026年1月 月次サマリー（ドラフト）

     ■ 売上
       売上合計: 258万円（税込）
       内訳:
       - コンサル: 145万円（56%）
       - 制作: 68万円（26%）
       - 人材紹介: 45万円（17%）

     ■ 原価・粗利
       外注費: 52万円
       粗利: 206万円（粗利率 80%）

     ■ 未確認事項
       ⚠️ 以下の入金消込をご確認ください：
       - 〇〇社 15万円（入金確認待ち）
       - △△社 20万円（請求中）

     売上集計シートに記録してよろしいですか？」
    ↓
[代表] 「〇〇社は入金済み、△△社はまだ」
    ↓
[エージェント]
    ├─ 入金ステータス更新
    ├─ 売上集計シートに記録
    └─ 「完了しました」
```

## 3. 人間との協働ポイント

### 3.1 承認が必要な操作

| カテゴリ | 操作 | 理由 |
|----------|------|------|
| 対外送信 | メール送信、請求書送付 | 対外コミュニケーションは人間が最終確認 |
| 金銭 | 金額確定、入金消込 | 経理上の正確性が必要 |
| 削除 | データ削除、ファイル削除 | 復元困難なため |
| 契約 | 契約書確定 | 法的拘束力があるため |

### 3.2 エスカレーションフロー

```
[通常タスク]
    ↓ 判断できる → 実行
    ↓ 判断できない
[代表に質問]
    ↓ 回答を得る → 実行
    ↓ 緊急/重大
[即時報告 + 対応提案]
```

### 3.3 フィードバックループ

```
[エージェント作業] → [代表レビュー] → [フィードバック] → [改善]
                                              ↓
                                    CLAUDE.mdに反映
                                    （判断基準の更新）
```
