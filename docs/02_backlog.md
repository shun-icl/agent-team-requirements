# 02. エージェント用バックログ（Agent Backlog）

> **目的**: エージェントチームが自律的に進められる粒度でタスクを定義
> **更新頻度**: 週次レビュー
> **MVPスコープ**: 2〜4週間で価値が出るアイテム

---

## 優先度の定義

| 優先度 | 意味 | 対応期限 |
|--------|------|----------|
| P0 | 最優先。これがないと業務が回らない | 1週間以内 |
| P1 | 高優先。MVP達成に必要 | 2週間以内 |
| P2 | 中優先。あると効率化できる | 4週間以内 |

## インパクトの定義

| 記号 | インパクト領域 |
|------|---------------|
| 💰 | 売上向上 |
| 📈 | 粗利改善 |
| ⏱️ | 時間削減 |
| ✅ | 品質向上 |

## エージェントへの指示ガイドライン

各タスクを実行する際、エージェントは以下を確認すること：

1. **前提条件**: 依存タスクが完了しているか
2. **成果物定義**: 何を作成するか明確か
3. **完了条件**: 何をもって完了とするか
4. **要確認事項**: 人間への確認が必要な点はあるか

### エージェントが自律実行可能な作業

- Notion DBの設計・構築
- Sheets/GASの作成
- ドキュメント/テンプレートの作成
- フォルダ構成の設計

### 人間の確認・承認が必要な作業

- 既存データの移行
- 権限設定の変更
- 外部サービスとの連携設定
- 契約・請求に関する最終承認
