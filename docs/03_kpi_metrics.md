# 03. KPI/計測設計（KPI & Metrics Design）

> **目的**: 事業KPIを週次で追跡可能にし、データドリブンな意思決定を実現する
> **更新頻度**: 指標定義は四半期レビュー、データは週次更新

---

## 1. KPI体系

### 1.1 KGI（Key Goal Indicators）

| 指標名 | 定義 | 目標値 | 計測頻度 |
|--------|------|--------|----------|
| 月間売上 | 当月の売上合計（税抜） | 800〜1,000万円 | 月次 |
| 粗利率 | (売上 - 原価) / 売上 × 100 | 70%以上 | 月次 |
| 顧客継続率 | 継続顧客数 / 前期顧客数 × 100 | 80%以上 | 四半期 |
| 代表稼働効率 | 売上 / 代表稼働時間 | 要設定 | 月次 |

### 1.2 KPI（Key Performance Indicators）

#### セールス系KPI

| 指標名 | 定義 | 計算式 | 目標値 | 頻度 |
|--------|------|--------|--------|------|
| 月間リード数 | 新規問い合わせ・紹介の件数 | COUNT(新規リード) | 要設定 | 週次 |
| 商談化率 | リードから商談に進んだ割合 | 商談数 / リード数 × 100 | 要設定 | 月次 |
| 商談数 | 初回商談を実施した件数 | COUNT(商談実施) | 要設定 | 週次 |
| 受注率 | 商談から受注に至った割合 | 受注数 / 商談数 × 100 | 要設定 | 月次 |
| 受注件数 | 契約締結した案件数 | COUNT(受注案件) | 要設定 | 月次 |
| 平均受注単価 | 受注1件あたりの平均金額 | 受注金額合計 / 受注件数 | 要設定 | 月次 |
| パイプライン金額 | 商談中案件の想定売上合計 | SUM(商談中案件.金額) | 要設定 | 週次 |

#### デリバリー系KPI

| 指標名 | 定義 | 計算式 | 目標値 | 頻度 |
|--------|------|--------|--------|------|
| 納品遅延率 | 期限超過した案件の割合 | 遅延案件数 / 全案件数 × 100 | 5%以下 | 月次 |
| 納品完了件数 | 当月納品完了した案件数 | COUNT(納品完了) | - | 月次 |
| 平均納品リードタイム | 受注から納品までの平均日数 | AVG(納品日 - 受注日) | 要設定 | 月次 |
| 手戻り発生率 | 初回納品後に修正が発生した割合 | 手戻り案件数 / 納品案件数 × 100 | 10%以下 | 月次 |

#### 財務系KPI

| 指標名 | 定義 | 計算式 | 目標値 | 頻度 |
|--------|------|--------|--------|------|
| 月間売上 | 当月売上合計（税抜） | SUM(売上) | 800〜1,000万 | 月次 |
| 月間粗利 | 売上 - 原価（外注費等） | 売上 - 原価 | 要設定 | 月次 |
| 粗利率 | 粗利 / 売上 × 100 | (売上 - 原価) / 売上 × 100 | 70%以上 | 月次 |
| 外注比率 | 外注費 / 売上 × 100 | 外注費 / 売上 × 100 | 要設定 | 月次 |
| 未入金額 | 請求済み未入金の金額 | SUM(未入金請求) | - | 週次 |
| 入金遅延率 | 支払期日超過の請求割合 | 遅延請求数 / 全請求数 × 100 | 5%以下 | 月次 |

#### リテンション系KPI

| 指標名 | 定義 | 計算式 | 目標値 | 頻度 |
|--------|------|--------|--------|------|
| 継続率 | 継続契約した顧客の割合 | 継続顧客数 / 対象顧客数 × 100 | 80%以上 | 四半期 |
| LTV | 顧客1社あたりの累計売上 | 累計売上 / 顧客数 | 要設定 | 四半期 |
| 追加受注率 | 既存顧客からの追加案件割合 | 追加案件数 / 既存顧客数 × 100 | 要設定 | 四半期 |
| 紹介獲得数 | 既存顧客からの紹介件数 | COUNT(紹介リード) | 要設定 | 月次 |

#### 運用効率系KPI

| 指標名 | 定義 | 計算式 | 目標値 | 頻度 |
|--------|------|--------|--------|------|
| 代表稼働時間 | 代表の月間稼働時間 | 実績記録 | 要設定 | 月次 |
| 案件あたり工数 | 1案件にかかる平均工数 | 総工数 / 案件数 | 要設定 | 月次 |
| テンプレ利用率 | テンプレ使用案件の割合 | テンプレ使用案件数 / 全案件数 × 100 | 要設定 | 月次 |

## 3. 指標定義詳細

### 3.1 セールス指標

#### リード数

| 項目 | 内容 |
|------|------|
| **定義** | 新規の問い合わせ・紹介として認識された件数 |
| **計算式** | COUNT(リードDB WHERE 登録日 IN 対象期間) |
| **データソース** | Notion リードDB |
| **計測タイミング** | リード登録時 |
| **責任者** | 要確認 |
| **注意点** | 同一顧客からの複数問い合わせは1リードとしてカウント |

#### 受注率

| 項目 | 内容 |
|------|------|
| **定義** | 商談から受注に至った割合 |
| **計算式** | 受注件数 / 商談件数 × 100 |
| **データソース** | Notion 案件DB |
| **計測タイミング** | 月末締め |
| **責任者** | 要確認 |
| **注意点** | 同月内に商談→受注が完結しない場合、コホート分析を検討 |

### 3.2 財務指標

#### 粗利率

| 項目 | 内容 |
|------|------|
| **定義** | 売上に対する粗利の割合 |
| **計算式** | (売上 - 原価) / 売上 × 100 |
| **データソース** | Sheets 売上集計シート |
| **原価の範囲** | 外注費、成果報酬費用（要確認） |
| **計測タイミング** | 月末締め |
| **責任者** | 要確認 |

#### 外注比率

| 項目 | 内容 |
|------|------|
| **定義** | 売上に対する外注費の割合 |
| **計算式** | 外注費 / 売上 × 100 |
| **データソース** | Sheets 売上集計シート |
| **計測タイミング** | 月末締め |
| **責任者** | 要確認 |

## 5. ダッシュボード設計（案）

### 5.1 エグゼクティブダッシュボード

**目的**: 代表が10秒で事業状況を把握

**表示項目**:
- 今月売上（目標比）
- 今月粗利率
- パイプライン金額
- 未入金額
- 今月受注件数

### 5.2 セールスダッシュボード

**目的**: リード〜受注のファネル可視化

**表示項目**:
- ファネルチャート（リード→商談→提案→受注）
- 週別リード推移
- 受注率トレンド
- 平均単価トレンド

### 5.3 デリバリーダッシュボード

**目的**: 納品状況と品質の可視化

**表示項目**:
- 進行中案件一覧
- 納品遅延案件（アラート）
- 手戻り発生案件
- 外注稼働状況
