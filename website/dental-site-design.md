#### 選ばれる3つの理由

**1. 現役の歯科医師が直接支援**
```
代表の楢原は、現在も口腔外科医として週2日臨床に立っています。
現場の空気感、スタッフとの関係性、患者対応の難しさ——
すべてを理解した上で、経営課題に向き合います。
```

**2. 採用から定着まで一気通貫**
```
求人原稿の作成、面接同席、入職後のフォローまで。
「採用して終わり」ではなく、定着・活躍までを支援します。
```

**3. 成果にコミットする伴走型**
```
月1回のレポート報告ではなく、
日々のコミュニケーションを通じて課題を共有。
院長の「右腕」として、一緒に医院を成長させます。
```
