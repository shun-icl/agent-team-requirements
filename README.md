# Agent Team Requirements

事業成長を加速するエージェントチームの要件定義書リポジトリ

---

## 概要

本リポジトリは、AIエージェント（Claude等）と人間チームが協働して事業成長を加速するための**要件定義・運用ドキュメント**を管理します。

### 対象事業
- ニッチ業界（歯科・医療・介護・中小企業）向けコンサルティング
- 人材紹介（成果報酬型）
- 制作（HP/LP/SNS/動画等）
- DX/業務改善支援
- 教材/テンプレート販売

### 目標
- 粗利率70%以上の維持
- 月商800〜1,000万円の達成
- 代表の稼働時間削減と売上の両立
- 属人化の解消と複製可能な運用体制の構築

---

## ドキュメント構成

```
docs/
├── 00_overview.md        # プロジェクト概要
├── 01_requirements.md    # 要件定義書本体（v0.1）
├── 02_backlog.md         # エージェント用バックログ
├── 03_kpi_metrics.md     # KPI/計測設計
└── 04_risks_security.md  # リスク/セキュリティ方針
```

| ドキュメント | 内容 | 更新頻度 |
|-------------|------|----------|
| 00_overview.md | 事業コンテキスト、対象領域、期待アウトカム | 四半期 |
| 01_requirements.md | 機能要件、非機能要件、受入基準、未決事項 | 随時 |
| 02_backlog.md | MVPバックログ、優先度、依存関係 | 週次 |
| 03_kpi_metrics.md | KPI定義、データソース、レポート設計 | 月次 |
| 04_risks_security.md | リスク対策、アクセス制御、個人情報方針 | 四半期 |

---

## 使い方

### 1. 要件の確認
`docs/01_requirements.md` を読み、現在の要件定義を把握してください。

### 2. バックログの実行
`docs/02_backlog.md` から優先度の高いタスクを選択し、実行します。

### 3. 進捗の更新
タスク完了時は、バックログの状態を更新してPRを作成してください。

### 4. KPIの計測
`docs/03_kpi_metrics.md` に従い、指標を計測・記録します。

## エージェント向けガイドライン

### できること
- ドキュメントの作成・更新
- Notion/Sheets/GASの設計・構築
- データ分析・レポート作成
- テンプレートの整備

### 人間の承認が必要なこと
- 外部サービスとの連携設定
- アクセス権限の変更
- 個人情報を含むデータの処理
- 契約・請求に関する最終決定
- データの削除

### 禁止事項
- 個人情報をプロンプトに含めること
- 権限設定の変更
- 決済・契約の自動実行
- 医療情報の処理

## ブランチ運用

| ブランチ | 用途 |
|---------|------|
| `main` | 承認済みの最新版 |
| `feature/*` | 新機能・変更の開発 |
| `fix/*` | バグ修正 |

### PRルール
- 変更内容を明確に記載
- 関連するバックログIDを記載
- レビュー後にmainへマージ

---

## 未決事項（優先対応）

以下の項目は、プロジェクト推進前に代表への確認が必要です：

1. 現在の主要ツール（案件管理、請求等）
2. 月間案件数の概算
3. 外注/パートナーの体制
4. 売上構成比（サービス別）
5. 個人情報（候補者情報等）の現在の保管場所

詳細は `docs/01_requirements.md` の「未決事項・質問リスト」を参照してください。
